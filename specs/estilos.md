## estilos do quiz

## contexto

quiz vizual com estilo minimalista com cores tons pastéis.

### regras

escrever apenas css relacionado aos estilos.
aplicar as classes nos elementos é permitido

### restrições

não escrever nenhum arquivo .js

### stack e padrões

crie e aplique css utilizando o padrão css BEM(Block Element Modifier)

### critérios de aceitação

html devidamente estilziado, com bom espaçamento levando em conta os elementos que vão aparecer e sumir enquanto a pessoa interage com o quiz

### verificação

todas as classes css seguem o padrão BEM e todos os elementos foram estilizados.
nenhuma classe foge do padrão.
todas as devidas classes css foram aplicadas.
